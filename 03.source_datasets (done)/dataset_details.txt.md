# Dataset Overview, Details and Facts

<br>

***Multivariate Gait Data***


---
The study dataset provide for this project consist of a sample of synthetic patients with time series data collected under different walking conditions and wearing a leg brace.  The file describes the data set as:

	Bilateral (left, right) joint angle (ankle, knee, hip) times series data collected from 10 healthy subjects under 3 walking conditions (unbraced, knee braced, ankle braced). For each condition, each subject’s data consists of 10 consecutive gait cycles.
	
Dataset Sourced from:	https://archive.ics.uci.edu/datasets	

This is a fantastic, clean dataset for a biomechanics, data science, or machine learning project. The Multivariate Gait Data dataset captures how bracing one joint affects the entire movement cycle across both legs. Since the brace is only applied to the right leg (either knee or ankle), you have a built-in control group (unbraced condition) and can look at both local changes and contralateral (opposite leg) adaptations.

***Record/Row Overview in File***


---
The file has separate records, each record indicating an observation for a patient or subjects as the person completes an entire gait cycle.

There would be a 1:M relation between subjects and gait cycles.  

The purpose of the file is to record human locomotion for 10 subjects with separate replications of a gait stride.

Data in the file consists of different data types including:

* Categorical
* Integer
* Continuous

After analyzing the file, new fields will be included for the categorical descriptions, as well.
